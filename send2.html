การติดตั้งระบบ

ค่าที่บันทึกจะเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น — ถ้าต้องการให้ทุกเครื่องใช้ค่าเดียวกันโดยไม่ต้องตั้งค่าเอง ให้แก้ DEFAULTS.apiUrl ในไฟล์ index.html ตรง ๆ แล้วเผยแพร่ไฟล์ให้ผู้ใช้

  1. สร้าง Google Sheet ใหม่ แล้วสร้างแท็บชีต 5 แท็บ: Students, Users, Assignments, Submissions, Settings
  2. คัดลอกหัวคอลัมน์ (แถว 1) ของแต่ละชีตตามแท็บ "โครงสร้าง Google Sheet" ให้ครบและตรงตัว — ชีต Assignments ต้องมีคอลัมน์ assignType และ assignStudents ด้วย (ใช้กับการมอบหมายรายบุคคล)
  3. เพิ่มผู้ใช้เริ่มต้นในชีต Users (เช่น admin | 1234 | admin | ผู้ดูแลระบบ | active) และรายชื่อนักเรียนในชีต Students
  4. ใน Google Sheet ไปที่ Extensions → Apps Script ลบโค้ดเดิมออก แล้ววางโค้ดทั้งหมดจากไฟล์ Code.gs ลงไฟล์ Code.gs แล้วกดบันทึก (Ctrl+S)
  5. กด Deploy → New deployment → เลือก Web app ตั้ง Execute as: Me และ Who has access: Anyone แล้วกด Deploy (ครั้งแรกจะขออนุญาตใช้สิทธิ์ Drive ให้กดอนุญาต)
  6. คัดลอก URL ของ Web App (ลงท้ายด้วย /exec) มาวางในแท็บ "ตั้งค่าเชื่อมต่อ" แล้วกดบันทึก
  7. ทดสอบเข้าสู่ระบบ — จากนั้นแก้ไข/อัปเดต index.html ได้ตลอดโดยไม่ต้องแตะ Apps Script หากเวอร์ชันใหม่ต้องการ Backend ใหม่ หน้าเว็บจะแจ้งเตือนเอง
  8. ผู้ใช้ระบบเดิมที่อัปเกรด: เพิ่มคอลัมน์ assignType และ assignStudents ในชีต Assignments (ต่อท้ายได้ ลำดับไม่สำคัญ) แล้วอัปเดต Code.gs แล้ว Deploy → Manage deployments → Version: New version — งานเดิมใช้ต่อได้ทันที
